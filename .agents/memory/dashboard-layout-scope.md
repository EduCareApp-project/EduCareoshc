---
name: Dashboard layout editing
description: Which dashboards can be rearranged, private drafts, and organisation-wide application.
---

Allow admin-level users to drag, reposition, and resize tiles on the Educator and Leadership dashboards. Guardian and school dashboards are outside this feature.

Edits are private to the administrator until they explicitly apply the layout to everyone in the organisation. Regular dashboard use remains fixed, with editing only in an explicit layout mode.

**Why:** The user wants to experiment with the design before locking it in, and explicitly chose Educator and Leadership dashboards with private drafts before applying to everyone.

**How to apply:** Keep private preview separate from the organisation's applied layout. Preserve tile functionality, do not silently lose unsaved arrangements, and do not let an older draft overwrite a newer applied layout.
