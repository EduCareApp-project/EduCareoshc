---
name: Finalised school report PDFs
description: Defines persistence and naming rules for finalised school report documents.
---

Finalising a school report must preserve its Reporting Obligations and save one immutable PDF in private object storage. The filename follows `Organisation - Service - Report Type - Year.pdf`.

**Why:** Finalised reports are historical records that may need to be reviewed, archived, or used as the basis for a corrected replacement without losing the original narrative or document.

**How to apply:** Do not regenerate a stored finalised PDF from later data changes. Archived reports retain their saved narrative and PDF; replacement reports are separate records.

School-report headings use the Global Settings email logo on the left and the Brand Kit company logo on the right, with “School Report” centred and one simple black line underneath.

**Why:** The user explicitly requested these two configured images, not a built-in EduCare asset or the organisation logo URL in Super Admin.

**How to apply:** Apply the heading to newly generated report PDFs and repeat it on continuation pages. Keep narrative below the heading without clipping long sections. Preserve already stored finalised PDFs.

Draft PDF previews open in a new window and must not save or finalise a report or create a persistent PDF. Include current editor text, even when it has not been saved.

**Why:** The user asked to inspect a sample before finalising and saving; requiring a save first would defeat that review step.

**How to apply:** Preview the same PDF layout and configured logos as finalisation, using the draft attendance snapshot and temporary narrative edits. Leave the original draft and finalised documents unchanged.
