---
name: Leadership utilisation reporting
description: Source and meaning of the Leadership Dashboard attendance and booking totals
---

The user wants a full-width Utilisation Data section beneath Recent Activity on the Leadership Dashboard, with three columns, graphs, and total bookings per session per site across all sites. Its source is attendance entered in the Reports tab of school accounts.

**Why:** The user explicitly identified the school-account attendance records as the source for this management view.

**How to apply:** Read current saved attendance rather than frozen statistics in finalised school report snapshots. Count session bookings, not unique children; do not imply capacity percentages without actual service capacities. Keep pupil-free attendance separate from ordinary ASC attendance so the same bookings are not counted twice, while showing both within the After School Care graph. The user approved that graph layout and requested separate booking categories in one shared table; its “Pupil-free days” column counts bookings, not operating days, because the row total must add all bookings.
