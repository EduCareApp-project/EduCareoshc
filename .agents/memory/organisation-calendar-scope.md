---
name: Educator organisation calendar
description: Shared calendar scope, dashboard placement, event ownership, and future service calendars.
---

Initially provide one shared organisation calendar on Educator dashboards. It must not change with the selected dashboard service.

Place it in the left dashboard column, keeping main navigation and all existing tiles. On mobile, the calendar comes before all other educator dashboard tiles.

These are the default positions. An administrator-applied dashboard layout may override tile positions and mobile reading order.

**Why:** The user subsequently chose admin-only drag/resize editing for Educator and Leadership dashboards, with private drafts before organisation-wide application.

All educators and leadership can add events. Staff manage their own events; admins and Educational Leaders manage any event.

**Why:** The user requested a month calendar and explicitly selected keeping navigation and allowing all educators and leadership to contribute with these ownership rules.

**How to apply:** Preserve the month view and shared scope when changing the dashboard. Do not convert this into the existing weekly learning-planning calendar.

Selecting a calendar day shows its date and events inline below the month grid, not in an events window. Event creation, editing and deletion confirmation can still use dialogs.

**Why:** The user explicitly requested the day and its events below the calendar rather than opening a window of events.

**How to apply:** Keep day selection within the dashboard calendar tile and preserve the existing event management permissions.

Future service calendars should support service-specific events linked to the service and organisation without crowding the global view.

**Why:** The user described separate service calendars as a future requirement, not part of the initial shared calendar.

**How to apply:** Keep organisation and service provenance available, and do not automatically mix service events into the global calendar.
