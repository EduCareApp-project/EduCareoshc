---
name: School report carry-forward
description: Defines which school-report data carries into a new reporting period or archived-report replacement.
---

New school reports inherit all saved Reporting Obligations from the Site's most recently finalised report. This applies to both replacements of archived reports and genuinely new reporting periods. Attendance statistics never carry forward; they are recalculated from the selected period's current generated attendance rows.

**Why:** Managers use the prior narrative as the starting point for the next report, but attendance figures must remain an accurate snapshot of the newly selected period. Existing edits in a current draft must not be overwritten by regeneration.

**How to apply:** When creating an empty draft, copy narrative from the latest finalised report for the same Site. When regenerating an existing draft, preserve any narrative already saved in that draft. Always refresh statistics from current attendance data.
