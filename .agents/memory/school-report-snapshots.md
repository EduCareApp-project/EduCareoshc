---
name: School report snapshots
description: Defines when generated school-report statistics and narrative content may change.
---

Generated Service Statistics are snapshots of the selected term attendance at generation time. Do not recalculate an existing report automatically when attendance later changes. Reporting Obligations remain editable while the report is a draft, then both sections lock on finalisation.

**Why:** A finalised PDF must remain a stable historical record, while staff still need to draft and save narrative obligations before committing it.

**How to apply:** New report outputs, exports, and views must read the stored statistics snapshot. Regeneration may refresh a draft snapshot, but must never alter a finalised report.
